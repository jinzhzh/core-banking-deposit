# 银行核心账务模拟器 - 零售存款子系统

## 概述

基于领域驱动设计（DDD）的银行核心账务模拟器零售存款子系统，实现完整的存款业务流程和会计核算。

## 核心能力

| 功能 | 说明 |
|------|------|
| 开户/销户 | 活期、定期账户开立与关闭 |
| 存取款 | 现金存入、现金支取 |
| 定活互转 | 活期转定期、定期转活期（含利息结算） |
| 利息计提 | 日终批处理，活期按日计息（年利率/360） |
| 冻结/解冻 | 司法冻结、质押冻结，冻结后限制可用余额 |
| 冲正 | 反向分录冲正，不修改历史流水 |
| 日切 | 切换会计日期，失败可回滚 |
| 对账 | 总账/明细账核对，生成日终对账报告 |

## 硬约束

1. **余额变动须双分录** — 每笔余额变动同时生成借方和贷方分录，借方合计必须等于贷方合计
2. **冲正不可改历史流水** — 冲正操作仅标记原流水为"已冲正"，通过生成反向分录实现
3. **日切失败可回滚** — 日切前创建快照，失败时恢复系统状态

## 项目结构

```
src/
├── config/          # 配置（利率、会计规则）
├── common/          # 公共模块（异常、枚举、工具类）
├── domain/          # 领域模型（账户、交易、分录等实体）
│   ├── models/      # 实体模型
│   ├── events/      # 领域事件
│   └── value_objects/ # 值对象
├── repository/      # 数据访问层
│   ├── interfaces/  # 仓储接口
│   └── memory/      # 内存实现（支持快照回滚）
├── service/         # 业务服务层
├── accounting/      # 会计引擎（分录、过账、总账、对账）
├── batch/           # 批处理（日终、利息计提、日切）
├── transaction_manager/ # 事务管理（工作单元、Saga）
├── report/          # 报表生成
├── api/             # API层
└── main.py          # 应用容器（依赖注入）
demo/
└── acceptance_demo.py  # 验收演示脚本
```

## 运行验收演示

```bash
cd core-banking-deposit
python3 demo/acceptance_demo.py
```

验收流程：开户存取 → 定活互转 → 冻结解冻 → 利息计提 → 日切 → 冲正 → 对账报告

## 技术栈

- Python 3.9+
- 纯内存实现（无外部数据库依赖）
- 领域驱动设计（DDD）
- 金额使用 Decimal 精确计算
- 线程安全的仓储实现

## 不在范围内

- 真实支付清算通道
- 持久化存储（数据库）
- Web API 框架
- 用户认证授权
